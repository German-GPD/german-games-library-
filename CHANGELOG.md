# Changelog

## 1.1.0 — 2026-10-25

- Expanded the catalogue to 160 game entries across open-world, racing, action, shooter, adventure, horror, simulation and puzzle genres.
- Added a separate filter for games on the recommendation list.
- Improved keyboard navigation, focus visibility and empty-letter handling.
- Added social sharing metadata and improved poster fallback behavior.
- Removed remote font imports; the interface uses system fonts.

## 1.0.0

- Initial responsive library, A–Z navigation, genre cards, search, status filters, game details and automatic light/dark theme.
\n\n## 1.2.0 — 2026-10-26\n\n- Added per-game playtime, achievements and completion tracking.\n- Added local JSON import/export.\n- Added optional Steam status API endpoint configuration without exposing API keys.\n- Documented Steam and Hydra integration limits.\n

## 1.4.0 — 2026-10-26

- Refined the premium neutral theme, card depth, spacing and mobile statistics layout.
- Expanded the catalog with games confirmed by the owner, including missing series entries and editions.
- Replaced guessed play statuses with owner-confirmed history; unverified catalog entries remain on the list.
- Removed generated playtime/achievement/completion estimates; completion stats now reflect confirmed completions only.
- Added a distinct “played, not completed” state and honest completion counters.
