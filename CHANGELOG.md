# Changelog

## 1.1.0 — 2026-10-25

- Expanded the catalogue to 160 game entries across open-world, racing, action, shooter, adventure, horror, simulation and puzzle genres.
- Added a separate filter for games on the recommendation list.
- Improved keyboard navigation, focus visibility and empty-letter handling.
- Added social sharing metadata and improved poster fallback behavior.
- Removed remote font imports; the interface uses system fonts.

## 1.0.0

- Initial responsive library, A–Z navigation, genre cards, search, status filters, game details and automatic light/dark theme.
