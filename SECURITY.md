# Security Policy

This is a static, client-side website. It does not have accounts, a backend, analytics, or a server-side database.

- Do not submit passwords, tokens, or other private data in issues.
- Report security concerns privately through GitHub's security reporting feature when available for this repository.
- The library stores optional game-status changes in the browser's local storage only.
- Game cover images are loaded from Steam's public CDN; normal browser network requests to that host may occur while viewing the site.
