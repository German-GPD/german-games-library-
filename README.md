# German'$ Games Library

Персональная игровая библиотека German'$ Team Coding — адаптивный каталог игр с алфавитом, жанрами и плитками в духе Steam.

**Сайт:** https://german-gpd.github.io/german-games-library-/

## Возможности

- Алфавит A–Z с количеством игр на каждую букву.
- Обложки, жанры и отметки «Знаю», «Играл» и «В списке».
- Поиск по названию, жанру и тегам.
- Фильтры по статусу («Знаю», «Играл», «В списке»), букве и жанру; сортировка по алфавиту или избранным.
- Светлая и тёмная темы автоматически следуют настройке устройства.
- Адаптивная вёрстка для телефона, планшета и компьютера.
- Окно с информацией об игре и ссылкой на Steam.
- Персональные изменения статусов, часы игры, достижения и прохождение хранятся локально в браузере.\n- Экспорт и импорт личной статистики в JSON.\n- Необязательный Steam status endpoint без хранения API-ключа на клиенте.
- Без аналитики, рекламы, аккаунтов и отправки пользовательских данных.

## Запуск через GitHub Pages

1. Открой Settings → Pages в репозитории.
2. В разделе Build and deployment выбери Deploy from a branch.
3. Укажи ветку main и папку /(root), затем нажми Save.

Сборка, npm-пакеты и серверная часть не требуются. В каталоге 180+ записей; часть — кандидаты для будущего, а не подтверждённые прохождения.

## Игровая статистика и интеграции\n\nОткрой игру и заполни часы, полученные/все достижения и статус прохождения. Данные хранятся локально в браузере; экспорт/импорт JSON доступен в блоке «Моя игровая статистика». Значения не угадываются автоматически.\n\nДля автоматического статуса Steam подготовлен `integrations/steam-worker.js` для Cloudflare Workers. Создай Worker и добавь secrets `STEAM_API_KEY` и `STEAM_ID` (SteamID64), при необходимости переменную `ALLOWED_ORIGIN=https://german-gpd.github.io`. Затем вставь URL Worker в поле «Адрес API-посредника» на сайте. Ключ хранится на стороне Worker, а не в JavaScript сайта. Профиль и сведения об игре должны быть доступны в настройках приватности Steam. Worker возвращает имя, аватар и текущую игру. Полная синхронизация часов и ачивок потребует дополнительной реализации Steam API `GetOwnedGames` и `GetPlayerAchievements`. У Hydra нет общедоступного облачного API для прямого подключения; пока можно использовать ручной ввод или импорт JSON.\n\n## Как добавить игру

Добавь объект в массив window.GAMES в файле js/games.js:

    {
      id: "example-game",
      title: "Example Game",
      letter: "E",
      genre: "Экшен",
      tags: ["Открытый мир", "Сюжет"],
      status: "candidate",
      appid: 123456,
      featured: false
    }

Статусы:
- played — играл или проходил;
- known — знакомая игра;
- candidate — рекомендация или игра на будущее.

Поле appid — Steam App ID. Если у игры нет страницы Steam, укажи 0: вместо обложки появится буквенная заглушка. Поле featured включает отметку избранного и приоритет при соответствующей сортировке.

Статус «Играл» выставляется только для игр, которые пользователь подтвердил. Статус «В списке» означает игру для будущего/проверки. Завершённые игры берутся из подтверждённой личной статистики; часы и достижения не угадываются. Изменения статусов сохраняются в локальном хранилище браузера и не редактируют исходный каталог.

## Изображения и права

Обложки подгружаются с CDN Steam по App ID. Изображения, названия и игровые бренды принадлежат соответствующим правообладателям. Проект не связан с Valve или издателями игр. Код лицензируется отдельно; лицензия не распространяется на сторонние игровые материалы.


## Достоверность личной статистики

Каталог и прохождения разделены: отметка «Играл» появляется только для подтверждённых игр. Статус завершения отражает ответы владельца библиотеки. Часы и достижения не генерируются автоматически; для них используй ручной ввод или импорт данных. Если в браузере сохранились оценки старой версии, помеченные как автоматически сгенерированные, они очищаются.
